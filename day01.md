## What I learned

DevOps helps development and operations work together
using automation and continuous feedback.

CI validates code changes through automated processes
such as build and testing.

Docker packages applications into images that can run
as containers.

AWS can provide cloud infrastructure such as EC2.

Monitoring helps us know whether the deployed application
and infrastructure are healthy.
